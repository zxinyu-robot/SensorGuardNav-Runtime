# 实验与评价口径

## 分层验证

1. **单元测试**：规则边界、角度回绕、滞回、状态转换、制动速度和恢复门控。
2. **合成回放**：确定性污染注入验证模式序列与诊断可重复性。
3. **真实rosbag**：在不控制机器人的shadow mode中统计检测延迟和误报。
4. **封闭场地**：限速、软障碍和独立急停下验证停车距离与恢复。
5. **生产试运行**：先只告警，再启用速度限制，最后才允许自动恢复。

## 推荐指标

- `detection_delay_frames`：污染开始到健康状态隔离；
- `false_degradation_rate`：正常片段被降级的比例；
- `unsafe_motion_time_s`：安全包络要求停车后仍有运动指令的时间；
- `maximum_pose_drift_m`：降级期间相对参考轨迹的最大漂移；
- `recovery_latency_s`：清洁完成到可信定位重新接管；
- `wrong_reacquisition_rate`：恢复到错误位姿的比例；
- `explainable_transition_rate`：具备完整原因和证据的转换比例。

合成demo只能证明软件状态转换可运行，不能用于报告真实检测率、定位漂移或安全性能。
不同场地、速度、传感器型号和污染材料必须分别标定和报告。
