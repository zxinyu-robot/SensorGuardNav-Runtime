# 检测、安全降级与恢复

## 检测

LiDAR单帧质量由有限值比例、有效点数比例、水平角覆盖、距离分布跨度和中值强度组成。
运动一致性比较 scan matching 与轮速平移，并比较 scan、IMU和轮速航向增量。所有指标先
归一化到 `[0, 1]`，再进入时间仲裁。

这些规则识别的是“数据不再适合当前定位链路”，不负责准确判断泥浆、灰尘、雨雾或硬件
损坏的物理类别。生产系统应保留原始证据，避免把环境退化误报为镜片污染。

## 可信度隔离

加权分数经过EMA和平滑窗口。低阈值和高阈值分离形成滞回，并要求连续坏帧或好帧后才改变
健康状态。该策略用于压制偶发稀疏帧，不应代替离线阈值标定。

## 安全降级

安全速度取以下上限的最小值：

- 正常或Dead Reckoning模式速度上限；
- 障碍观测视场对应的速度上限；
- 定位不确定性对应的速度上限；
- 最近障碍物、反应延迟和制动减速度给出的制动距离上限。

不存在有效障碍观测、视场低于硬阈值、不确定性过大或降级超时时，速度直接为零。

## 恢复

恢复门控首先要求连续健康帧，然后按证据选择：

- 局部残差、预测误差和歧义均较低：局部重定位；
- 局部条件不满足，但预测范围和歧义仍可控：全局重定位；
- 候选位姿无法安全区分：人工介入；
- 证据不足：继续停车等待。

接入真实系统时，应把ICP/NDT残差、ScanContext候选差距和AMCL粒子分布转换为这里的统一
恢复证据，并对恢复后的位姿跳变做速度门控。
